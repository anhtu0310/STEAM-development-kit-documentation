Introduction
============
 
The **STEAM Development Kit** is an open-source hardware project that
provides a complete, ready-to-build electronics platform for STEAM
(Science, Technology, Engineering, Arts, and Mathematics) learning and
prototyping. All design files are released openly and were created in
Altium Designer, making the project easy to review, modify, and
manufacture.
 
The repository is organized into two independent hardware designs:
 
- **ESP32S3 Controller** -- a standalone MCU board built around the
  ESP32-S3, which can operate on its own as a general-purpose
  development board.
- **STEAM Dev Kit** -- the main development kit board, which combines
  the controller with a set of onboard peripherals, sensors, and LEDs
  for hands-on STEAM experimentation.
